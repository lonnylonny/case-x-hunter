## 待决定与边界

2026-10-23 用户确认：

- 仅开放输出上限 2048/4096 tokens，默认 4096；温度固定 0。
- Top K 为 1–10 的严格整数，初始为 4，放在设置页高级区域。
- 非密钥设置保存于 PostgreSQL 独立设置表，刷新、重启和上传替换后保留。
- 同一实例的网页/API 共用，CLI 继续使用显式实验参数。API 显式 Top K 覆盖本次请求，省略时使用实例值。
- 保存后下一次请求生效，无需重启；进行中的请求使用开始时配置。
- 用户允许在改动较小时增加 OpenAI；核对官方接口与本项目 DeepSeek 专用参数后，本轮维持仅 DeepSeek。共享 SDK 不代表模型参数完全兼容，未增加任意端点或模型选择。
- 用户明确授权必要的真实付费验证，不以模型回放替代真实服务验收。
