## 验收标准

- [ ] 提供固定 CSV 模板、完整可用示例、必填列及合法主数据说明；一行一 Case/Detail/Evidence。
- [ ] 严格复用业务校验，不编造必填事实，不自动提升 review 状态。
- [ ] 错误指明可定位的行列和原因；解析、校验或写入失败时旧数据仍可查询。
- [ ] 成功后只查询当前数据集，来源定位正确；显示名称、案例数与更新时间。
- [ ] 替换原子完成，重启后数据保留；原始样例、评估集、标签与实验记录不被修改。
- [ ] 为上传数据登记明确身份和可用性依据，不绕过时点约束或沿用旧数据效果指标。

## 待决定与边界

先收敛模板列与快照身份/可用时点设计；若无法满足冻结模型，记录冲突并审阅，不以通用 title/body 模型替代。并发查询一致性、大小上限、重复 ID 规则待定。
