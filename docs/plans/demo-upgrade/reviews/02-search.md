## 三个拟展示问题

### A：焊线脱落与界面剥离（Q001）

> PROD_001 在 OQC 发现焊线脱落，拉力检查显示焊点剥离，涉及客户 CUS_001、生产批 DEV_PL_001、客户批 DEV_CL_001，原因尚未确认。

实际候选：**C001 → C003 → C004 → C007**。

| 历史来源 | 原文 | Agent 的验收建议（待确认） |
|---|---|---|
| C001 / E001 | 拉力试验的剥离面位于 die pad；界面复查发现表面污染。清洁对照样品的接合表现恢复。 | 可解释界面剥离的历史调查参考；污染是历史结论，当前尚未证明。 |
| C003 / E003 | 焊点剥离面存在 pad 表面污染；清洁处理后的对照样品未再出现同类界面剥离。 | 可依据当前焊点剥离与历史第一焊点界面现象说明参考价值；当前未提供第一／第二焊点位置，不能称位置完全相同。 |
| C004 / E004 | 断口均位于二焊点颈部，显微检查显示局部成形不良；未观察到 pad 界面剥离或污染。 | 必须说明颈部断裂与界面剥离的差异。是否仍有弱参考价值由用户判断，不能靠同站点或同 failure_mode_id 自动采用。 |
| C007 / E007 | 拉力试验显示金球从焊盘表面脱开，分离面位于键合界面；键合设备 EQ_WB_04 的 loop 参数复核发现设定偏离作业标准，调整参数后的对照样品未再出现同类分离。 | 历史界面分离具有参考价值，但需工程师检查 loop 参数叙述与历史原因之间的支持强度。原文可追溯不等于这条合成因果叙述已经合理。 |

历史原因：C001、C003 为“结案确认：die pad或lead/substrate bond finger污染/氧化。”；C004 为“结案确认：neck/stitch区域成形不良。”；C007 为“结案确认：Wire Bond参数不当，键合界面结合强度不足。”

当前缺口草稿：具体剥离位置、界面复查结果及当前参数调查记录未提供，会影响与不同历史机制的对照。不得将当前客户、产品、批号说成缺失；不得将当前原因确定为污染或参数不当。

用户审阅重点：**C004 是否仍值得作为弱参考？C007 的合成检查与历史原因搭配是否适合公开演示？** 如认为 C007 需修正，先记录领域修订方案，不直接改动已绑定快照的源数据。

实际候选：**C006 → C009 → C005 → C008**。

| 历史来源 | 原文 | Agent 的验收建议（待确认） |
|---|---|---|
| C006 / E006 | 出货 AOI 记录中锡球完整；收货样品显示边缘碰伤及掉球，运输防护检查发现相应接触痕迹。 | 缺球与碰伤现象提供参考依据；当前未提供出货记录和运输防护调查，不能宣称当前已确认运输原因。 |

用户审阅重点：**C009 应跳过，还是有明确的差异参考价值？缺口是否贴近实际调查初期？**

## 工程师确认栏

可按以下格式答复，无需重新标注 45 对 qrels：

1. 示例：A／B／C 可用，或指出要替换的问题。问题是否符合调查初期已知信息？
2. 边界：C004、C009 分别可参考／不足以参考／需补条件，附一句依据；C007 与 E008 是否存在不适合演示的工程叙述？
3. 缺口：认可上述草稿，或列出最重要的修正。

默认待审；用户确认后在本表记录原话和适用范围。展示验收意见不自动生成正式标签，不把软件测试通过视为回答质量通过。
